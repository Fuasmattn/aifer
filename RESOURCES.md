# Agentic AI Resources

## Knowledge

- [Building Effective AI Agents — Anthropic (engineering blog)](https://www.anthropic.com/engineering/building-effective-agents)
  The most widely-referenced definition in the industry: draws the line between a "workflow" (fixed,
  human-designed steps) and an "agent" (the model directs its own steps and tool use). Written for
  engineers but the framing is plain-language-adjacent. Use for: the canonical Agent vs Workflow
  distinction, and Anthropic's own definition of "agent."
- [Agentic AI, explained — MIT Sloan](https://mitsloan.mit.edu/ideas-made-to-matter/agentic-ai-explained)
  Business-school-level explainer, vendor-neutral, written for executives rather than engineers. Use for:
  plain-English framing and the "proactive colleague vs. assistant that waits to be asked" analogy.
- [What is Agentic AI? — IBM](https://www.ibm.com/think/topics/agentic-ai)
  Vendor explainer but relatively balanced; names the three defining traits (autonomy, goal-driven
  behavior, adaptability). Use for: cross-checking the glossary's "agentic" definition.
- [AI agents: four use cases for accountants — ICAEW](https://www.icaew.com/insights/viewpoints-on-the-news/2025/nov-2025/ai-agents-four-use-cases-for-accountants)
  and [Four AI agent use cases for finance teams — ICAEW](https://www.icaew.com/insights/viewpoints-on-the-news/2026/jul-2026/four-ai-agent-use-cases-for-finance-teams)
  Written by the accountants' own professional body (Institute of Chartered Accountants in England and
  Wales) — the highest-trust source available for this specific audience. Use for: every work-context
  example in lessons; prefer these over generic vendor blog posts.
- [What is an AI Agent Harness? — Databricks](https://www.databricks.com/blog/ai-harness)
  and [What Is an Agent Harness? A Beginner's Guide — DataCamp](https://www.datacamp.com/blog/agent-harness)
  Use for: "harness" and "sandbox" definitions, and the reason-act-observe agent loop.
- [LLM context windows: what they are & how they work — Redis](https://redis.io/blog/llm-context-windows/)
  Use for: the token / context window definitions and the "working memory" analogy.
