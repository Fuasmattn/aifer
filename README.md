# aifer

Five short, practical lessons on what "agentic AI" actually means — no coding, no unexplained jargon.
Written for someone catching up on the buzzword at work and at home, not for someone building the
technology.

**Live site:** https://Fuasmattn.github.io/aifer/

## Contents

- `index.html` — table of contents
- `lessons/0001`–`0005` — the lessons themselves, in order
- `reference/glossary.html` — every term used, defined once, with a work and a private-life example each
- `MISSION.md` — who this was written for and why
- `RESOURCES.md` — the primary sources everything is grounded in (Anthropic, MIT Sloan, IBM, ICAEW,
  Databricks, Redis)

Available in English, German, and Spanish — switch in the top-right corner of any page.

## Local preview

No build step. Open `index.html` directly in a browser, or serve the directory:

```
python3 -m http.server
```

## Deployment

Static site, deployed via GitHub Pages from the `main` branch root.
